Install GSP32

A MicroPython web UI for ESP32 boards. Plug your board in with a USB data cable and install it right from this page.

Use Chrome or Edge on a Desktop Computer

This page talks to the board over a USB cable. Phones, tablets, Firefox, and Safari cannot do that. Open this page in Google Chrome or Microsoft Edge on a desktop computer.

  1. 1. Plug In Your Board
  2. →
  3. 2. Click Get Started
  4. →
  5. 3. Install or Set Up Wi-Fi

Works in Chrome or Edge on a computer.

Don't See Your Board?

  1. Use a Data Cable. Some USB cables only charge. Try another cable you know carries data.
  2. Try Another Port. Plug the board straight into the computer instead of a hub or dock.
  3. Install the USB Driver. Look at the small chip next to the board's USB port: "CP2102" or "CP2104" needs the Silicon Labs CP210x Driver; "CH340" or "CH341" needs the WCH CH340 Driver.
  4. Hold BOOT While Plugging In. Hold the board's BOOT button, plug the cable in, then let go.
  5. Try Again. Click Get Started and pick the board's port.
