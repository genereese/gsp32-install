Install GSP32

GSP32 is a MicroPython web UI for ESP32 boards. This page installs it from your browser.

Use Chrome or Edge on a desktop computer

This page talks to the board over a USB cable. Phones, tablets, Firefox, and Safari cannot do that. Open this page in Google Chrome or Microsoft Edge on a desktop computer.

Install

  • A classic ESP32 board
  • A USB data cable
  • Google Chrome or Microsoft Edge on a desktop computer

Installing deletes everything already stored on the board.

Keep this tab open and visible during the install. If you switch away, the install can slow down or fail.

Use Chrome or Edge on a desktop computer. Open this page on localhost or HTTPS, then try again.

This tab is hidden. Bring it back and keep it visible until the install finishes.

The install did not finish. Unplug the board, plug it back in, and try again. Close other programs that use the serial port, such as Arduino, Thonny, and mpremote. If it still fails, try another USB cable and another port.

The firmware is on the board. The install window can set up Wi-Fi too. You can also do it here.

You can use the board over USB, with no Wi-Fi.

  • In the serial console below, click Connect. The speed is 115200.
  • Or from a terminal: mpremote connect /dev/ttyUSB0 on Linux, the cu.usbserial port on Mac, or COMx on Windows.

Reset the board and press Enter when it says “Press Enter within 10 s” to set up Wi-Fi from the USB console.
