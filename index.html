Install GSP32

A MicroPython web UI for ESP32 and ESP32-S3 boards. Plug your board in with a USB data cable and install it right from this page; it picks the right firmware for your chip.

Use Chrome or Edge on a Desktop Computer

This page talks to the board over a USB cable. Phones, tablets, Firefox, and Safari cannot do that. Open this page in Google Chrome or Microsoft Edge on a desktop computer.

  1. 1. Plug In Your Board
  2. →
  3. 2. Click Get Started
  4. →
  5. 3. Install or Set Up Wi-Fi

Works in Chrome or Edge on a computer.

Don't See Your Board?

  1. Use a Data Cable. Some USB cables only charge. Try another cable you know carries data.
  2. Try Another Port. Plug the board straight into the computer instead of a hub or dock.
  3. Install the USB Driver. Look at the small chip next to the board's USB port: "CP2102" or "CP2104" needs the Silicon Labs CP210x Driver; "CH340" or "CH341" needs the WCH CH340 Driver.
  4. Hold BOOT While Plugging In. Hold the board's BOOT button, plug the cable in, then let go.
  5. Try Again. Click Get Started and pick the board's port.

Install GSP32

Installs Loading...

After the install, set Wi-Fi at the board's >>> prompt (Thonny or any serial terminal): import gsp, then gsp.wifi('name', 'password'). From GSP32-C Beta V118 the board then has its own small page at http://its address (status, run, stop, restart); the first visit sets its password. From V119 it also serves live pages (values, graphs, buttons) and a Console page; from V120 a file manager (Files: upload, edit, move, delete); from V121 a Settings page, and Wi-Fi can also be set with an Improv Wi-Fi serial tool; from V122 the AI Helper, Pin Panel, Backup and the Tutorial; from V123 the Package Manager, Dashboards and Bluetooth (S3); from V124 Devices (pair nearby boards, shared values and messages over encrypted ESP-NOW); from V125 the move from the old GSP32 (restore its backup: pages, settings and main.py carry over), the microSD card, and Set Up Wi-Fi here. V117 has no web page. Choose Stable for the full GSP32 with its web UI.
