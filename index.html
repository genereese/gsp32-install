Install GSP32

GSP32 is a MicroPython web UI for ESP32 boards. Plug your board in with a USB data cable and install it right from this page.

Use Chrome or Edge on a Desktop Computer

This page talks to the board over a USB cable. Phones, tablets, Firefox, and Safari cannot do that. Open this page in Google Chrome or Microsoft Edge on a desktop computer.

Install GSP32

You need a classic ESP32 board and a USB data cable (some cables only charge).

Installing erases everything on the board: your programs, files, and Wi-Fi settings.

    USB Only

    GSP32 is installed for USB use.

    • Use the console below, or mpremote connect COMx (Windows), /dev/ttyUSB0 (Linux), or the cu.usbserial port (Mac).
    • To add Wi-Fi later, click Set Up Wi-Fi above.

    Something Went Wrong

    • The console below shows what happened. Click Copy Log to share it.
    • Unplug the board, plug it back in, and try again.
    • Close Arduino, Thonny, mpremote, and other programs that use the port.
