Install GSP32

GSP32 is a MicroPython web UI for ESP32 boards. This page installs it from your browser.

What you need

  • A classic ESP32 board
  • A USB data cable
  • Google Chrome or Microsoft Edge on a desktop computer

Install

  1. Plug the board into this computer with the USB data cable.
  2. Click Install GSP32 and pick the port for your board.
  3. Wait for the flash to finish. Leave the board plugged in.
  4. Enter your Wi-Fi name and password when asked.

This erases the board. Anything already stored on it is deleted.

This browser has no Web Serial support, so firmware cannot be installed from this page. Open it in Google Chrome or Microsoft Edge on a desktop computer. The browser will not open a serial port from this address. Use HTTPS, or open the page on localhost, then try again.

Getting Started

Open http://gsp32.local, or the IP address shown after setup.

On the first visit, set a password for the web UI.

If Wi-Fi setup was skipped, use a serial console: press Enter at the “Press Enter within 10 s” prompt.
